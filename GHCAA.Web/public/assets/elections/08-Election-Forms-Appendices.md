# Election Forms — Appendices

These appendices govern how the forms in Parts I and II are signed, moved and kept. They
are read alongside the forms; they are not themselves forms to be completed.

## Appendix A — Mandatory Signature Matrix

A form is not valid until every signature marked Required has been given. Optional means
the signature is taken if the person is present, and their absence is recorded on the form.

| Document | Chief Election Commissioner | Election Commissioner | Observer | Candidate Agent | Presiding Officer |
|----------|-----|----|----------|-----------------|-------------------|
| Poll Opening (ER-15) | Required | | Required | Optional | Required |
| Poll Closing (ER-18) | Required | Required | Required | Optional | Required |
| Ballot Sealing (ER-19) | Required | Required | Required | Optional | Required |
| Counting Start (ER-20) | Required | Required | Required | Optional | |
| Counting Completion (ER-29) | Required | Required | Required | Optional | |
| Result Certification (ER-30) | Required | Required | Required | | |
| Handover (ER-37) | Required | | | | |

## Appendix B — Chain of Custody

Election materials pass through the following documents in order. Each step is evidenced
by the form named against it, and no step may be skipped.

1. Election materials issued
2. Material Receipt Register (ER-39)
3. Polling Officer verification
4. Poll Opening Certificate (ER-15)
5. Voting
6. Poll Closing Certificate (ER-18)
7. Ballot Box Sealing Certificate (ER-19)
8. Counting Authorization (ER-20)
9. Ballot Box Opening Certificate (ER-21)
10. Vote Counting Sheets (ER-23)
11. Independent Tally Sheets (ER-24)
12. Result Certification (ER-30)
13. Election Archive Register (ER-38)
14. Executive Committee Handover (ER-37)
15. Election Closure Certificate (ER-40)

## Appendix C — Record Retention

| Record | Minimum Retention |
|---------|-------------------|
| Ballot Papers | 3 years, or until all appeals conclude, whichever is later |
| Result Sheets | Permanent |
| Election Certificates | Permanent |
| Complaints | 10 years |
| Appeals | 10 years |
| Tribunal Decisions | Permanent |
| Registers | Permanent |
| Election Reports | Permanent |
| Handover Records | Permanent |

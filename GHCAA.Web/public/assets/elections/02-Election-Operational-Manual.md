# 1. Introduction

This manual describes every operational activity required to conduct an election.

Every Election Commissioner, Polling Officer, Observer and Technical Administrator shall follow this manual.

Deviation shall only occur by written order of the Chief Election Commissioner.

• Voter verification

• Poll supervision

• Ballot security

---

Responsible for

• Electronic voting

• System monitoring

• Server security

• Audit logs

• Database backup

---

## Observer

Responsible for

• Independent observation

• Compliance verification

• Reporting irregularities

Observers shall not interfere with election activities.
